Политика обработки персональных данных

Настоящая страница описывает, какие данные могут передаваться через форму записи на сайте «Шинторг Сервис» и для каких целей они используются.

1. Какие данные передаются

При отправке заявки пользователь может указать имя, номер телефона, выбранную услугу, дату и время записи.

2. Для чего используются данные

Данные используются для связи с клиентом, подтверждения записи, уточнения деталей обслуживания и ведения учёта заявок.

3. Передача заявки

Данные формы передаются через технический сервис обработки заявки и могут сохраняться в рабочей таблице для учёта обращений. Доступ к данным должен предоставляться только лицам, которым он необходим для обработки заявок.

4. Срок хранения

Срок хранения данных определяется оператором сайта с учётом целей обработки и применимых требований законодательства.

5. Контакты

По вопросам, связанным с заявкой и обработкой персональных данных, можно связаться по телефону +7 952 955 47 47.
