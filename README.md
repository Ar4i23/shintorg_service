# 🚗 Шинторг Сервис — сайт автосервиса в Воронеже

![Превью сайта](img/preview.png)

🔗 **Live-демо:** https://ar4i23.github.io/shintorg_service/

Лендинг автосервиса «Шинторг Сервис»: прайс на 40 услуг с категориями,
онлайн-запись с календарём свободных дат, отзывы, контакты с маршрутом
до сервиса в Яндекс Навигаторе.

📍 Воронеж, пр-т Революции, 1В · «Крутим шины — чиним машины!»

---

## 🛠 Стек

- **HTML5** — семантика, классы по БЭМ
- **CSS** — модульная архитектура: файл на блок, точка входа `css/style.css`
- **JavaScript** — Vanilla, ES-модули, без зависимостей и сборщиков

---

## ✨ Возможности

- 📱 Полный адаптив: мобильные → планшет → десктоп
- 🧾 Прайс: 10 категорий-табов, 40 услуг, кнопка «Записаться» у каждой строки
  (услуга сама подставляется в форму)
- 📅 Запись: real-time валидация полей, календарь — свободные даты
  регулируются через Google-таблицу
- ✅ Модалка успешной отправки + отправка заявки в Telegram-бот
- 💬 Карусель отзывов на мобильных (свайп, точки, автопрокрутка)
- 🧭 Кнопка маршрута — открывает Яндекс Навигатор с готовым маршрутом
- ♿ Доступность: фокус-стили, ARIA, `prefers-reduced-motion`

## 🧱 Структура сайта

Страница собрана из следующих секций (сверху вниз):

| #   | Секция          | БЭМ-блок    | Содержание                                                                                       |
| --- | --------------- | ----------- | ------------------------------------------------------------------------------------------------ |
| 1   | Шапка           | `header`    | Логотип, меню (бургер на мобильных), кнопка «Записаться»; липнет при скролле                     |
| 2   | Герой           | `hero`      | Слоган «Крутим шины — чиним машины!», фото цеха, CTA                                             |
| 3   | Что мы чиним    | `price`     | 10 категорий-табов, 40 услуг с ценами, кнопки «Записаться», плашка «Не нашли работу — позвоните» |
| 4   | Слово мастера   | `guarantee` | Гарантия 1 год, фото реального цеха, бейджи достижений                                           |
| 5   | Отзывы клиентов | `reviews`   | 6 реальных отзывов с Яндекс Карт; карусель на мобильных, сетка на десктопе                       |
| 6   | Запись          | `cta`       | Форма: имя, телефон, выбор услуги, календарь свободных дат; real-time валидация                  |
| 7   | Контакты        | `contacts`  | Телефон, адрес, Telegram/MAX, маршрут в Яндекс Навигаторе                                        |
| 8   | Подвал          | `footer`    | Логотип, навигация, копирайт                                                                     |

Плюс модальное окно успешной отправки (`modal`) — открывается после записи.

**Навигация по якорям:** Главная → `#hero`, Услуги → `#services`,
Гарантия → `#guarantee`, Отзывы → `#reviews`, Контакты → `#contacts`.

## 🚀 Быстрый старт

```bash
git clone <ссылка на репозиторий>
cd shintorg-service
```

Открой через локальный сервер (ES-модули **не работают** с `file://`):

- VS Code → расширение **Live Server** → правый клик по `index.html` → Open with Live Server
- или `python -m http.server 8000` → http://localhost:8000

## ⚙️ Настройка под заказчика

| Что                                         | Где менять                                 |
| ------------------------------------------- | ------------------------------------------ |
| Телефон, Telegram, MAX, координаты маршрута | `index.html`                               |
| Токен и chat_id бота заявок                 | `js/modules/telegram.js` → `TG_CONFIG`     |
| Ссылка на таблицу свободных дат             | `js/modules/calendar.js` → `SHEET_CSV_URL` |
| Режим календаря (whitelist/blacklist)       | `js/modules/calendar.js` → `MODE`          |
| Логотип и фото                              | папка `img/`                               |
