# 🚗 Шинторг Сервис — сайт автосервиса

Современный адаптивный сайт автосервиса **«Шинторг Сервис»** в Воронеже.

Проект разработан с акцентом на понятную структуру, удобную навигацию, мобильную адаптацию и удобную запись на обслуживание.

## ✨ Возможности

- адаптивная верстка для мобильных устройств, планшетов и desktop;
- современный дизайн автосервиса;
- каталог услуг;
- категории ремонтных работ;
- цены на услуги;
- блок гарантии;
- отзывы клиентов;
- контактная информация;
- форма записи на обслуживание;
- интеграция с мессенджером;
- ссылка на отзывы в Яндекс Картах;
- мобильное меню;
- плавная навигация по странице;
- интерактивные элементы интерфейса.
