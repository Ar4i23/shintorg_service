## v1.1 — исправления по результатам визуальной проверки (2026-09-30)

### 1. Валидация имени

- Файл: `js/modules/validation.js`
- Было: регулярное выражение принимало и латинские, и кириллические буквы.
- Стало: принимаются только русские буквы `А-Я/а-я/Ё/ё`, минимум 2 символа.
- Почему: это соответствует исходному требованию формы — заявки должны оформляться с русским именем.
- Ограничения по пробелам, цифрам и другим символам сохранены.

### 2. Текст ошибки имени

- Файл: `index.html`
- Было: «русские или латинские».
- Стало: «минимум 2 русские буквы».
- Почему: подсказка теперь точно соответствует фактической валидации.

### 3. Логотип

- Файл: `img/logo.webp`
- Причина: при предыдущей оптимизации PNG был преобразован в WebP без сохранения прозрачности.
- Исправление: логотип заново конвертирован из исходного PNG в WebP с сохранением альфа-канала.
- Результат: прозрачный фон логотипа снова работает на тёмном фоне сайта, при этом используется оптимизированный WebP.

## v1.2 — бэкенд онлайн-записи и живое расписание (2026-10-01)

Большой день: сайт из лендинга превратился в систему записи.

### Google Apps Script (Code.gs) — полный бэкенд

- `doPost`: приём заявок. Проверки перед записью:
  - `user-limit` — одна активная заявка на номер (разблокировка по статусу
    «завершено» или автоматически, когда время записи прошло);
  - `once-busy` — лимит «1 запись в час» на «Компьютерную диагностику»
    и «Сход-развал»;
  - `full` — слот закрыт вручную или заполнен (SLOT_CAPACITY=5).
- `doGet`: расписание для сайта, считается на лету из таблицы (заявки + блокировки).
- `LockService` — защита от гонки при одновременных заявках.
- `setupSheets` — разовая настройка таблицы (заголовки, список статусов).
- Меню «ШИНТОРГ» прямо в Google Sheets: открыть/закрыть день.
- Токен Telegram хранится в Script Properties (не в коде, безопасно для GitHub).

### Структура данных

- `Sheet1`: добавлены колонки F–I (Дата записи, Время, Статус, Device),
  статусы «новая / в работе / завершено» через выпадающий список.
- Новый лист `Блокировки`: заказчик закрывает слоты под офлайн-записи
  без единой строчки кода.
- Лист `График` (в работе): исключения — открыть выходной / закрыть рабочий день.

### Багфиксы бэкенда

- Чтение дат через `getDisplayValues()` вместо `getValues()` — часовые пояса
  больше не сдвигают дату записи на день назад (слоты считались неверно).
- Телефон в колонке C падал как `#ERROR!` (Sheets воспринимал «+7...» как
  формулу) — колонка переведена в текстовый формат.

### Фронтенд

- `js/modules/preselect.js`: при переходе «Записаться» из каталога подсвечиваются
  сразу оба обязательных поля — имя и телефон.
- `js/modules/form.js`: обработка ошибок `closed` и `invalid` с понятными текстами.
- `js/modules/calendar.js` + form: слоты обновляются сразу после заявки (5 → 4).
- `index.html`: исправлена битая SVG-трубка (в path были подчёркивания вместо
  пробелов) + `transform-box/origin` для анимации вокруг центра.
- `index.html`: исправлена tel-ссылка (пробелы → `tel:+79529554747`).
- `index.html`: согласие с политикой в форме стало кликабельной ссылкой.
