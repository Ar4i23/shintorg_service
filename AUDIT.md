# Аудит проекта — Шинторг Сервис

Дата аудита: 2026-09-29

## Что уже хорошо

- Проект не является простой статической страницей: есть модульный JavaScript.
- CSS разбит по БЭМ-блокам.
- Есть адаптивная навигация, вкладки, календарь, форма, валидация, модальные окна.
- Есть коммерческий сценарий записи.
- Есть телефон и адрес.
- Есть реальные отзывы и ссылка на Яндекс Карты.
- В проекте уже была интеграция с Google Apps Script для расписания/заявок.

## Критические находки

### 1. Ложный success формы

Раньше при ошибке запроса к Google Apps Script код переходил к Telegram fallback и затем мог вызвать `success()` даже при пустом Telegram-конфиге.

Риск: пользователь видел «Заявка отправлена», хотя фактической доставки могло не произойти.

Исправлено: при ошибке endpoint пользователь получает сообщение об ошибке и инструкцию позвонить.

### 2. Telegram-токен в frontend

В проекте присутствовал модуль, рассчитанный на вставку `botToken` и `chatId` непосредственно в JavaScript.

Так делать нельзя: всё, что находится в клиентском JS, доступно посетителю сайта.

Исправлено: прямой Telegram fallback удалён. Telegram должен обрабатываться серверной частью / Apps Script.

### 3. Заглушки социальных ссылок

В HTML были ссылки `https://t.me/USERNAME` и `https://max.ru/USERNAME`.

Исправлено: вместо нерабочих ссылок оставлен реальный телефон и понятный сценарий связи.

### 4. Неверный alt у логотипа

В alt логотипа оставалось название другого проекта: «Вася починит!».

Исправлено на «Шинторг Сервис».

### 5. Дублирование подключения Google Fonts

Шрифты подключались одновременно через `<link>` в HTML и через `@import` в CSS.

Исправлено: оставлено одно подключение через `<link>` с preconnect.

### 6. Тяжёлые изображения

Исходные PNG:

- logo.png — около 0.5 MB;
- master_1.png — около 1.4 MB;
- master_2.png — около 2.4 MB;
- preview.png — около 5.4 MB.

Для сайта добавлены WebP-версии. Это существенно уменьшает объём загрузки изображений.

### 7. Несоответствие валидации имени

Сообщение об ошибке говорило, что разрешены русские или латинские буквы, но регулярное выражение принимало только кириллицу.

Исправлено: разрешены латинские и кириллические буквы.

### 8. Форматирование даты

Дата заявки формировалась через `new Date("YYYY-MM-DD").toLocaleDateString(...)`, что может давать сдвиг даты в некоторых часовых поясах.

Исправлено: дата форматируется напрямую из ISO-строки.

## Что пока не считаем завершённым

- Серверная часть Apps Script не входит в архив, поэтому её код нельзя полноценно проверить.
- Нельзя гарантировать доставку Telegram/Google Sheets без живого теста endpoint.
- Политику персональных данных необходимо проверить и заполнить оператором перед публикацией.
- Для боевого домена нужно заменить demo URL в canonical/Open Graph.
